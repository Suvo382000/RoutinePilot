Features

Everything you need to manage schedules

Built for academic institutions of all sizes — from small schools to large universities.

📋

Smart Routine Builder

Create weekly class schedules with drag-and-drop simplicity. Supports theory (1hr) and lab (4hr) classes with automatic break management.

⚡

Conflict Detection

Automatically detects when a teacher is double-booked across multiple routines. Prevents scheduling conflicts before they happen.

🔔

Real-time Notifications

Students get instant alerts when their class changes. Notifications are targeted — only the affected class group is notified.

👨‍🏫

Substitute Management

Teachers report absences directly. Admin assigns substitutes with one click. Students see who's taking the class automatically.

🏢

Department Management

Add, rename, or remove departments. All linked teachers, students, and routines update automatically when a department is renamed.

🔒

Role-based Access

Three distinct roles — Admin, Teacher, Student — each with their own dashboard, permissions, and view of the schedule.

How It Works

Simple workflow, powerful results

From setup to daily use — everything works in a few steps.

01

Admin sets up departments & teachers

Create departments (CSE, IT, ECE…), add teacher accounts with their designation (HOD, Associate, Assistant) and faculty type (Permanent/Visiting).

02

Build class routines

Create weekly routines for each department, year, and semester. Assign teachers to theory (1hr) or lab (4hr) slots. The system checks for conflicts automatically.

03

Teachers & students access their schedules

Teachers see only their assigned classes. Students see their department's full timetable. Everyone gets a clean, day-highlighted view.

04

Absence & substitute flow

Teacher reports absence → Admin gets notified → Admin approves and assigns substitute → Only affected students get a targeted notification with the substitute's name.
